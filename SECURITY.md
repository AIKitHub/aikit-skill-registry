# Security Policy

## Reporting issues

If you find a security problem (for example, credentials accidentally committed to this repository), **do not** open a public issue.

Report privately via:

1. [GitHub private vulnerability reporting](https://github.com/AIKitHub/aikit-skill-registry/security/advisories/new) (when enabled)
2. Direct contact with the maintainers

## Your responsibilities

- Do not commit database passwords, API tokens, or private URLs to this registry or your project.
- Use read-only database accounts when installing MCP integrations.
- Complete OAuth / browser login steps yourself; do not share session tokens.

## Third-party software

Entries in this registry link to external packages and repositories. Review upstream licenses and permissions before installing.
