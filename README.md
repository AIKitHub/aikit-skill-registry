# aikit-skill-registry

**English** | [简体中文](README.zh-CN.md)

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

A catalog of third-party Agent Skills. Send your Agent a one-liner with a link; it fetches the index and install instructions, then installs into your project.

> Do not commit passwords, API tokens, or private URLs. See [SECURITY.md](SECURITY.md).

## Links

| Resource | URL |
|----------|-----|
| Repository | https://github.com/AIKitHub/aikit-skill-registry |
| **Install instructions** | [docs/install.md](docs/install.md) |
| **Skill index** | https://raw.githubusercontent.com/AIKitHub/aikit-skill-registry/main/registry/skills.json |

## Install (copy & paste to your Agent)

```text
Install AIKitHub Skill:
https://github.com/AIKitHub/aikit-skill-registry/blob/main/docs/install.md
```

Optionally include a skill `id` in the same message; otherwise the Agent lists available ids.
